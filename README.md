# HOOKIT STUDIO

전문직(변호사, 의사, 세무사 등)을 위한 **매출 전환 릴스 제작·운영 대행** 서비스(및 웹·앱 구축)를 소개하고, 문의를 받는 **원페이지 랜딩 사이트**입니다.
문구 초안은 [docs/site_content.md](docs/site_content.md), 사이트 텍스트는 `src/constants/siteContent.ts`에서 수정합니다.

## 페이지 구성 (한 페이지, 위에서 아래로)
1. **히어로** — "보기 좋은 영상을 넘어 팔리는 영상으로"
2. **서비스** — 편집·후보정, 캡션, 썸네일, 전자책, 스케줄링, 자동 DM (+ 웹·앱 구축)
3. **3331 전략** — 노출형 3 / 인간미형 3 / 전문가형 3 / 모집형 1
4. **진행 과정** — 상담 → 기획 → 제작 → 운영 → 리포트
5. **문의** — 카카오톡 버튼, 메일 버튼
6. **푸터**

가격과 작업 사례는 공개하지 않습니다. (가격은 영업 때 안내, 포트폴리오는 준비되면 추가)

## 기술 스택
- React + TypeScript
- Vite

## 실행
```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드
```
