## 2. 회사 소개

**HOOKIT STUDIO**는 릴스 영상을 만들어 드리는 팀이 아닙니다.
**콘텐츠를 본 사람이 다음 행동을 하도록 설계하는 릴스 대행 스튜디오**입니다.

많은 콘텐츠 회사가 많은 편수와 높은 조회수를 내세웁니다.
저희는 적은 편수와 상대적으로 낮은 조회수로도 실제 고객 행동과 매출을 만드는 데 집중합니다.

> 상품과 관계없는 10만 명이 보는 것보다, 구매 가능성이 높은 타깃 3천 명이 보고 행동하는 것이 더 중요합니다.

**저희가 만드는 고객 행동**
프로필 방문 · 팔로우 · 댓글 · 자동 DM 유입 · 자료 신청 · 상담 문의 · 결제

## 3. 서비스 소개: 3331 릴스 전략

릴스 10편을 아래 4가지 유형으로 구성해, 사람을 고객으로 바꾸는 흐름을 만듭니다.

| 유형 | 편수 | 하는 일 |
|------|------|---------|
| 노출형 | 3편 | 새로운 타깃을 계정으로 데려오고 평균 노출도를 높입니다 |
| 인간미형 | 3편 | 대표자와 브랜드에 친밀감과 호감을 만듭니다 |
| 전문가형 | 3편 | 전문성을 증명하고 댓글, DM, 팔로우로 잠재고객을 모읍니다 |
| 모집형 | 1편 | 문의와 매출로 전환합니다 |

**노출 → 호감 → 신뢰 → 잠재고객 확보 → 매출**

### 노출형 3편: 계정을 발견하게 합니다
- 비팔로워에게 도달하고 신규 타깃을 유입시킵니다
- 프로필 방문과 계정의 평균 노출도를 높입니다
- 이후 콘텐츠가 소비될 기반을 만듭니다

### 인간미형 3편: 머물게 합니다
- 사람들은 전문성만으로 상품을 사지 않고, 대표자의 성격, 가치관, 태도를 보고 신뢰를 판단합니다
- 심리적 거리를 줄이고 프로필 이탈을 막습니다
- 노출형이 사람을 데려왔다면, 인간미형은 그 사람이 계정에 머물게 합니다

### 전문가형 3편: 잠재고객으로 바꿉니다
전문 정보 제공 → 댓글 CTA → 자동 DM → 팔로우 → PDF·체크리스트 제공 → 잠재고객 확보

조회수가 높지 않아도 핵심 타깃이 댓글을 남기고 팔로우하면 좋은 콘텐츠입니다.

### 모집형 1편: 매출로 전환합니다
상품 소개, 고객 문제 제시, 해결 방법 안내, 상담 신청 유도로 이어집니다.
먼저 구매할 이유를 만든 뒤 판매합니다.

### 추가 서비스: 웹 · 앱 구축
개발자와 디자이너가 팀에 함께 있어 웹과 앱 모두 직접 구축합니다.
- 릴스에서 유입된 고객이 상담 문의까지 이어지도록 설계한 홈페이지, 웹 서비스, 앱
- 릴스 콘텐츠 전략과 같은 흐름(노출 → 신뢰 → 문의)으로 기획부터 디자인, 개발까지
- 릴스 대행과 함께 진행하거나, 웹·앱 구축만 따로 의뢰도 가능합니다

> 가격은 공개하지 않고 영업 시 안내

## 4. 왜 HOOKIT STUDIO인가 (어필 포인트)

1. **조회수가 아니라 행동으로 평가합니다**
   유형별로 맡은 역할이 다르므로 성과 기준도 다르게 봅니다.
   - 노출형: 비팔로워 도달, 총노출, 프로필 방문, 공유
   - 인간미형: 시청 유지, 댓글, 좋아요, 팔로워 반응
   - 전문가형: 댓글 수, 자동 DM 발송 수, 자료 신청 수, 신규 팔로워, 잠재고객 수
   - 모집형: 상담 신청, DM 문의, 링크 클릭, 결제

2. **판매 상품을 먼저 정하고 콘텐츠를 기획합니다**
   타깃에 대한 이해도가 곧 전환율이라고 보기 때문에, 판매 상품을 먼저 정한 뒤 그에 맞춰 노출형, 인간미형, 전문가형 순으로 기획합니다.

3. **첫 업로드는 반드시 노출형으로 시작합니다**
   계정의 평균 노출도(노출 체력)를 먼저 확보해야 이후 콘텐츠가 볼 사람이 부족하지 않습니다.

4. **광고는 구조 위에서 증폭합니다**
   광고는 콘텐츠 전략을 대신하지 않습니다. 이미 만들어진 전환 구조를 키우는 수단으로 씁니다.
   저희 운영 경험상, 평균 노출도가 높은 계정일수록 광고 효율이 좋아지는 경향이 있었습니다.
   (확정된 플랫폼 공식은 아니며, 광고 전후의 자연노출과 유료노출을 구분해 데이터로 계속 검증합니다.)

5. **전문가형 콘텐츠에 자동 DM과 자료 제공을 설계합니다**
   댓글 한 번으로 DM과 자료가 이어져 잠재고객 명단이 쌓이는 구조입니다.

## 5. 진행 과정

1. **상담**: 판매 상품과 타깃 확인
2. **기획**: 3331 구성에 맞춰 10편 기획
3. **제작·업로드**: 노출형부터 순서대로 (노출형 → 인간미형 → 전문가형을 섞어 진행, 마지막에 모집형)
4. **전환 운영**: 자동 DM, 자료 제공, 필요한 콘텐츠에 광고 집행
5. **성과 확인**: 유형별 지표 리포트

권장 업로드 순서: 노출 → 인간미 → 전문가 → 노출 → 인간미 → 전문가 → 노출 → 인간미 → 전문가 → 모집
